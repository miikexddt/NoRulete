# 🎡 NoRulete - Ruleta de la Mala Suerte

[![GitHub license](https://img.shields.io/github/license/miikexddt/NoRulete)](https://github.com/miikexddt/NoRulete/blob/main/LICENSE)
[![GitHub stars](https://img.shields.io/github/stars/miikexddt/NoRulete)](https://github.com/miikexddt/NoRulete/stargazers)

**NoRulete** es una herramienta web moderna y dinámica diseñada para profesores, dinamizadores de grupos y cualquier persona que necesite realizar sorteos aleatorios con un toque de emoción. Con una interfaz premium y efectos de sonido vibrantes, convierte la selección de participantes en un momento esperado.

---

## ✨ Características Principales

- **🎮 Dos Modos de Juego:**
    - **Sorteo de Grupos:** Ideal para definir el orden de exposición en clases o reuniones. Todos participan y se define un orden secuencial.
    - **Sorteo General:** Define un número específico de ganadores y eliminados ("salados").
- **🛡️ Modo Oficial:** Activa un sistema de transparencia con registro de giros y reinicios, ideal para sorteos legales o institucionales.
- **📄 Exportación PDF:** Genera un reporte profesional de los resultados con un solo clic.
- **🔊 Experiencia Inmersiva:** Sonidos sincronizados, voces y una interfaz "glassmorphica" con animaciones suaves.
- **🏠 Pantalla de Bienvenida:** Un video de inicio impactante que establece el tono de la aplicación desde el primer segundo.

---

## 🚀 Tecnologías Utilizadas

- **Core:** HTML5, CSS3, JavaScript (Vanilla JS).
- **Librerías:**
    - [html2canvas](https://html2canvas.hertzen.com/) para captura de resultados.
    - [jsPDF](https://github.com/parallax/jsPDF) para generación de reportes.
- **Diseño:** CSS Custom Properties, animaciones de alto rendimiento.

---

## 🛠️ Instalación y Uso

No requiere instalación de servidores ni bases de datos. Es una **SPA (Single Page Application)** que funciona directamente en el navegador.

1. Clona este repositorio:
   ```bash
   git clone https://github.com/miikexddt/NoRulete.git
   ```
2. Abre `index.html` en tu navegador favorito.
3. ¡Comienza a girar!
